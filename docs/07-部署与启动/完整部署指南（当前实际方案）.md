> ⚠️ 公开密钥（`sb_publishable_`前缀）可以安全放在前端代码里，它只有有限权限，不是管理员密钥。

### 数据库表结构

数据库建表脚本在 `supabase-setup.sql`，共4张表：

| 表名 | 作用 |
|---|---|
| `users` | 用户信息（昵称、头像、积分、背包、好友列表） |
| `posts` | 论坛帖子 + 朋友圈（区分 `post_type: forum / moments`） |
| `friend_requests` | 好友申请（pending / accepted / rejected） |
| `messages` | 私信消息（支持已读/未读标记） |

### 如果需要重建数据库（新建 Supabase 项目时）

1. 登录 `https://app.supabase.com`
2. 进入项目 → **SQL Editor**
3. 把 `supabase-setup.sql` 的内容粘贴进去，点 **Run**
4. 进入 **Database → Replication** → 把 `messages` 表加入 Realtime 复制
5. 更新 `js/api-client.js` 顶部的 `SUPABASE_URL` 和 `SUPABASE_KEY` 为新项目的值

## 本地开发

本地开发**不需要**启动任何后端服务器，直接连接云端 Supabase 即可。

```bash
# 方法1：Python 简易服务器
python -m http.server 8080
# 然后访问 http://localhost:8080/

# 方法2：双击运行
启动网站服务器.bat
```

本地开发时的数据（用户、帖子等）和线上共享同一个 Supabase 数据库。

## 常见问题

**Q：论坛/好友功能显示错误？**  
A：打开浏览器 F12 控制台，看是否有 Supabase 报错。大多数情况是网络问题，刷新即可。

**Q：数据没有保存？**  
A：检查 `js/api-client.js` 里的 `SUPABASE_URL` 和 `SUPABASE_KEY` 是否正确。

**Q：推送代码后网站没更新？**  
A：等待 1-3 分钟，或按 Ctrl+F5 强制刷新缓存。

**Q：`server/` 文件夹是干什么的？**  
A：历史遗留，是早期用 Node.js + MongoDB 搭建的后端方案，已被 Supabase 完全替代，**不需要启动，可以忽略**。
