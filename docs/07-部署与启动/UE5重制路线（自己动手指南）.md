# 🎮 UE5 重制路线 —— 自己动手指南

> **先说实话**：把现在这个校园模拟器做到《三角洲行动·黑鹰坠落》的画质，
> 用 UE5 是可行的方向，但这是一个**从零重做**的大工程，而且：
>
> - UE5 成品是**几个 GB 的本地程序，无法在网页里跑** —— 你会失去网页版。
> - 黑鹰坠落级画质需要**专业的高模、PBR贴图、材质** —— 这些 3D 美术资产
>   既不能靠写代码生成，也需要专门的美术功底。
> - 这是 C++/蓝图的另一套技术栈，全职做也要**数月**。
>
> 我（AI）**无法替你操作 UE5**。但下面给你一条能自己起步的完整路线。
> 如果你只是想要"更好看"，**继续优化现在的 Three.js 网页版**性价比高得多。

## 如果你确实想试 UE5，按这个顺序来

### 第1步：确认电脑配置
UE5 对硬件要求高，建议至少：
- 显卡：RTX 2060 以上（你装了 ComfyUI，应该有 N 卡，OK）
- 内存：16GB 以上（32GB 更稳）
- 硬盘：留出 100GB+（引擎本体 ~30GB + 项目）

### 第2步：下载 UE5
1. 装 **Epic Games Launcher**：https://store.epicgames.com/zh-CN/download
2. 注册/登录 Epic 账号
3. 在启动器里点「虚幻引擎 Unreal Engine」→「库」→ 安装最新 **UE 5.4** 或 5.5
4. 等待下载（~30GB，较慢）

### 第3步：第一个项目
1. 打开 UE5 → 新建项目
2. 选「游戏」→「第一人称」模板（自带角色移动+第一人称，跟你现在的漫游最接近）
3. 质量预设选「最大」，勾「初学者内容包」
4. 创建 → 进编辑器，按 ▶ 就能用 WASD 走动了

### 第4步：免费高质量素材（不用自己建模！）
UE5 最大优势是有海量免费素材：
- **Fab**（原 Quixel Megascans）：https://www.fab.com —— 照片级扫描的树木、地面、石头、建筑，全免费
- **City Sample / 城市样板**：Epic 官方免费的整座城市，可拆来用
- 在编辑器里：内容侧边栏 → Fab → 搜 "school" / "classroom" / "tree" → 一键导入

### 第5步：搭校园
- 用 BSP/几何体快速拉出教学楼体块
- 往墙面拖 Fab 的混凝土材质
- 地面用 Landscape（地形）刷草地
- 摆 Fab 的树/长椅/路灯（路灯直接用带光源的蓝图）
- 光照：放一个 Directional Light（太阳）+ Sky Atmosphere + Lumen（UE5 自带全局光，开箱即黑鹰坠落级）

### 第6步：打包
- 平台 → Windows → 打包项目 → 得到 .exe（几个 GB）
- 这就是独立的本地游戏，跟网页/Electron 版完全分开
