# 🖥️ 本地启动指南

> 本地开发**不需要**启动任何后端服务器。  
> 后端用的是云端 Supabase，本地直接连接即可。

---

## 启动方法

### 方法1：双击运行（最简单）

双击项目根目录的 `启动网站服务器.bat`，浏览器会自动打开。

### 方法2：命令行

```bash
# Python 3（推荐）
python -m http.server 8080

# 然后访问
http://localhost:8080/
```

---
