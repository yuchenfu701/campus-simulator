# 🔄 软件版（Electron）增量更新发布流程

> 已接入 **electron-updater**：用户电脑上的软件每次启动会自动检查 GitHub Releases，
> 发现新版后**只下载改动的字节块**（NSIS 差分 `.blockmap`），不是整包重下。
> 账号数据存在 Supabase 云端 + 本地 `userData` 目录，更新**不会丢失**。

---

## 一次大更新的完整发布步骤

### 第1步：改完代码后，提升版本号
编辑 `package.json` 顶部的 `version`，按规则递增：
```json
"version": "2.0.1"   // 2.0.0 → 2.0.1（小修复）或 2.1.0（新功能）
```
> ⚠️ 版本号必须比线上高，否则用户端不会提示更新。

### 第2步：设置 GitHub Token（仅首次）
electron-builder 上传到 Releases 需要一个有 `repo` 权限的 token：
1. 打开 https://github.com/settings/tokens → Generate new token (classic)
2. 勾选 `repo`，生成后复制
3. 在 PowerShell 设置环境变量（每次发布前，或写进系统环境变量永久保存）：
```powershell
$env:GH_TOKEN = "你的token"
```

### 第3步：一键打包并发布
```powershell
npm run release
```
这条命令会：
- 用 electron-builder 打包 Windows 安装包
- 自动生成差分文件：`latest.yml` + `*.exe.blockmap`
- 自动上传到 GitHub Releases（草稿状态）

### 第4步：在 GitHub 发布草稿
1. 打开 https://github.com/yuchenfu701/campus-simulator/releases
2. 找到刚上传的草稿（Draft）
3. 填写更新说明（会显示在用户的更新弹窗里）
4. 点 **Publish release**

### 完成 ✅
其他电脑上的软件下次启动（5秒后）就会：
1. 检测到新版本 → 弹出更新窗口
2. 用户点"立即更新" → **只下载改动的部分**（可能几 MB 而非整包 ~150MB）
3. 下载完点"立即安装" → 自动重启到新版，**账号数据保留**

## 网页更新如何同步到软件版？

**自动同步** —— 软件版加载的就是仓库里同一批 `.html / .js / .css` 文件。
所以你给网页做的所有改动（加载动画、画质优化、bug修复等）**已经在软件版里了**，
只要按上面流程重新 `npm run release` 发一个新版本即可。

## 常见问题

**Q：差分更新失败会怎样？**
A：代码里有降级——差分失败会自动打开 GitHub 发布页让用户手动下整包，不会卡死。

**Q：开发时（npm start）会弹更新吗？**
A：不会。代码用 `app.isPackaged` 判断，只有正式安装版才检查更新。

**Q：便携版（portable）支持增量吗？**
A：不支持差分，便携版每次是整包。增量更新只对 NSIS 安装版有效。

**Q：第一次用户从哪装？**
A：首次安装仍需从 Releases 下载完整安装包（download.html 已配置）。装好后以后都是增量。
