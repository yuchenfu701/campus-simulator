# Night-sky image sources

- `milkyway-nasa-2k.jpg` is a downsampled display copy of NASA Scientific Visualization Studio's [Deep Star Maps 2020](https://svs.gsfc.nasa.gov/4851/) 4K EXR. Credit: NASA/Goddard Space Flight Center Scientific Visualization Studio; ESA/Gaia/DPAC. Generated by `tools/prepare_nasa_sky.py`.
- `moon-nasa-lroc-2k.jpg` is NASA Scientific Visualization Studio's [CGI Moon Kit](https://svs.gsfc.nasa.gov/4720/) LROC color map. Credit: NASA/GSFC Scientific Visualization Studio.
- `moon-nasa-disc.png` is a spherical projection of that LROC map, generated by `tools/prepare_nasa_moon.py`.

These images are used as visual references in a fictional, accelerated day-night simulation. Moon phase and star movement are simulated for visual variety; they do not reproduce the real sky for a geographic location and date.
